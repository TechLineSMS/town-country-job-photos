# Town & Country Job Photos

Job-site photos posted from the Town & Country TechLine app, attached to Jobber job notes.

Files are pushed here automatically by the "Town & Country App (Copy)" Make.com scenario so that Jobber can fetch them via a URL with a real file extension in the path (`raw.githubusercontent.com/.../photos/job-XXXX-timestamp.jpg`), which Google Drive's link format can't provide.
